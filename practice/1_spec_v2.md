# 任务级 Spec:Agent Loop Demo(v2)

## 目标
实现一个最小可运行的 Agent Loop demo:LLM 按结构化协议决策,按需调用模拟工具,把结果回填上下文,循环直到给出最终回答;全程可观测、可重复运行。

## 业务约束
- 调用 deepseek-v4-flash,决策只允许两种结构化输出:{"type":"tool_call",...} 或 {"type":"final_answer",...};代码只按 type 字段分支,不从自然语言里猜意图
- 模拟工具两个,固定返回,不调用任何真实外部 API:1) get_date 查当前日期 2) get_weather 查城市天气
- 每一步打印执行结果:决策内容、调用了哪个工具、输入、输出
- 循环必须有步数上限 max_steps=5:超限时终止运行并报错,不得死循环
- 模型输出解析失败时:打印失败日志与原始输出,重试 1 次;仍失败则报错终止,不得把原始文本当作最终答案返回

## 需要修改
- 新增单文件:practice/1_spec_v2.py(单一 Python 类)
- 允许在 .gitignore 追加 __pycache__/
- 除以上外不改动任何代码

## 验收标准
- 输入“今天是星期几?北京的天气如何?”时,在 ≤3 轮循环内输出最终回答,回答包含星期几、城市、天气、温度四个要素,且不含 JSON 片段或多余解释
- 同一输入连续运行 3 次,每轮均出现成对的 tool_start/tool_end 日志,无解析失败
- 将 max_steps 临时改为 1 运行:程序报“步数超限”并终止,而非死循环
- 解析失败路径可验证:临时把 llm_decide 的返回 mock 成非 JSON 字符串后运行,程序打印解析失败日志、重试一次,然后报错终止
- git diff 不含上述新增以外的改动
